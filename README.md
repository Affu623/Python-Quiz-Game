**🧠 Python Quiz Game**
This is a basic Python quiz game built using input() statements, if-else conditions, and score tracking. The game asks the player multiple general knowledge questions and assigns points based on correct answers.

**📌 Features**
Interactive question-answer format

Score tracking system

Simple conditional logic

Beginner-friendly Python code

**💻 How to Run**
Make sure you have Python installed on your system.

Clone this repo or download the .ipynb file.

Run the notebook using Jupyter Notebook or any compatible IDE (e.g., VSCode).

bash
Copy code
python quiz_game.py  # if you convert to .py

**📝 Sample Questions**

How many days are there in a week?

How many letters are there in the English alphabet?

How many days are there in a year?

Name the national bird of India?

📈 Scoring System
Points are awarded based on correct answers. Try your best to get the highest score!
